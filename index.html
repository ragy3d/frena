    ¿Qué app abre?

    Que salte solo al abrir Mercado Pago

    Esta app sola no puede espiar qué otras apps abrís — ningún sitio web puede, y está bien que sea así. Lo que sí se puede es que el celular la abra automáticamente. Se configura una vez:

    🤖 Android
    1. Instalá MacroDroid de la Play Store (es gratis).
    2. Agregar macro → Disparador → Aplicaciones → «Aplicación iniciada/cerrada» → elegí Mercado Pago → Iniciada.
    3. Acción → Aplicaciones → Abrir sitio web → pegá:
    4. Guardala y dale el permiso de accesibilidad que te pide (lo necesita para saber qué app se abrió).
    🍎 iPhone
    1. Abrí Atajos (viene con el iPhone) → pestaña Automatización → +.
    2. Elegí App → Mercado Pago → Se abre → Ejecutar inmediatamente.
    3. Nueva automatización en blanco → Añadir acción → Abrir URL → pegá:
    4. Listo.
